# 🌸 Forever Petals - Pipe Cleaner Flower Shop

Handmade pipe cleaner flowers, bouquets and gifts web app.

## Features
- Browse flowers, bouquets and gifts
- Custom bouquet builder (flower, color, stems, wrapping, message card)
- Cart and checkout
- Payment: Cash on Delivery and UPI (with transaction ID)
- Admin orders page

## Tech Stack
Python, Flask, SQLite, HTML, CSS

## How to Run
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000
Admin: http://127.0.0.1:5000/admin?key=petal123
